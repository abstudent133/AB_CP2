# Personal Project Portfolio Launcher
***

## Overview
This project is a python-based portfolio launcher that allows users to explore and run multiple independent programs from a single interface. It acts as a central hub for showcasing different projects, each demonstrating specific programming concepts and skills. The program uses a menu-driven interface to display project descriptions and gives users the option to run each project directly.

---

## Features
- Interactive menu system for navigating projects  
- Built-in descriptions explaining each project  
- Ability to launch individual programs from one place  
- Continuous loop for repeated use until the user exits  

---

## Included Projects

1. Movie Recommender
2. Geometric Calculator
3. Simple Gradebook
4. Morse Code Translator

---

## How to Run

1. Ensure all project folders are in the correct directory structure:
project_root/
- main.py
- geomentric_calculator/
- movie_recomender_folder/
- class_relationship/
- morse_code.py


2. Install any required dependencies (if applicable):
- tkinter (usually included with Python)
- 

3. Run the main program:
python main.py


4. Use the menu to:
- View project descriptions  
- Run individual programs  
- Exit the application  

---

## Requirements
- Python 3.x  
- All project files must be accessible from the main script  

---

## Notes
- File and folder names must match exactly as written in the import statements  
- Each project must contain a `main()` function to run correctly  
- The program will not start if any import fails
